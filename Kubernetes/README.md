# Kubernetes Labs

Hands-on Kubernetes administration using a two-node kubeadm cluster.

## Labs
- Lab 9: Cluster Setup with kubeadm and Flannel CNI
- Lab 10: Node Taints and Labels
- Lab 11: Namespace and ResourceQuota
- Lab 12: ConfigMap, Secret, MySQL StatefulSet and Headless Service

## Cluster
- Control Plane: nti-virtual-machine
- Worker: k8s-worker
- Kubernetes: v1.35.9
- CNI: Flannel
